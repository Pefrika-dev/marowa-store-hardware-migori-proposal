Credits, licences and an honest disclaimer.

This is an independent design and engineering proposal. It is not an official Marowa Store website, it was not commissioned by the store, and it does not process real orders or payments.

Not affiliated or commissioned

Not an official store website. Marowa Store has not reviewed, approved or commissioned this project. Product names, prices, stock states and specifications are sample data created to demonstrate an interface. The only verified store details used here are the publicly supplied phone number, email address and location description.

Project & developer

Digital Commerce Concept Designed & Developed by Thomas Hondo Chacha — Software Engineer. The concept, information architecture, interface design, frontend code and demonstration data were prepared independently as a proposal. No official Marowa Store brand assets, logo files or internal records were used. The “M” mark in the header is an original typographic placeholder, not the store's official logo.

The site is a static frontend. It has no backend API, authentication service, payment integration or shared database. Cart and quotation records are stored in the browser's localStorage and can be cleared at any time. The admin access code is deliberately public and is not production security.

Typography & icons

Archivo, Inter and IBM Plex Mono are self-hosted local webfont files, distributed under the SIL Open Font License 1.1. Archivo is by Omnibus-Type, Inter by Rasmus Andersson, and IBM Plex Mono by IBM. No Google Fonts request is made at runtime.
