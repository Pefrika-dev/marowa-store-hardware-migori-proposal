    Demo data & storage

    Browser-local only

    Local storage used—

    State is stored under marowa.demo.state.v1. Export a JSON snapshot before resetting if you want to keep a demonstration state.

    Reset demonstration

    Destructive

    Resetting restores the original seeded demo catalogue, quotations, inquiries and settings. Cart and quotation list are cleared. This cannot be undone unless you exported a backup.

    Security boundary

    Important

    This admin is a frontend demonstration. The public access code is not authentication. A production system needs a server-side API, hashed passwords, session management, role-based access control, request validation, rate limiting and audit logging. See credits and the README for the documented reference architecture.
